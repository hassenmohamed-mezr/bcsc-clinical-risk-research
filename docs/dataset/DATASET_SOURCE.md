## Dataset Description

This research uses the BCSC Risk Estimation Dataset, which contains aggregated screening mammography records and associated breast cancer outcomes.

The dataset includes information about screening mammograms and breast cancer outcomes (invasive cancer or ductal carcinoma in situ) within one year after the index mammogram.
