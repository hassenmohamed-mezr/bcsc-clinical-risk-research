# Exploratory Data Analysis

## Evidence

The preserved notebook `notebooks/02_eda/EDA.ipynb` contains weighted
descriptive analysis and visualizations for demographic, breast-density,
reproductive, family-history, and medical features. It calculates cancer rates
using `count` as a frequency weight and includes a training-split summary.

## Observed findings

The notebook contains weighted summaries and plots. The overall cancer rate
printed by the existing execution is approximately 0.4863% in the current
workspace copy. This value is documented as an observed notebook output, not as
a general population estimate.

## Limitations

This is exploratory analysis. It does not establish predictive performance,
causality, or clinical validity. The category-code meanings and external data
provenance require verification.
