# Documentation

This directory contains evidence-based documentation for the reorganized BCSC
Risk Estimation project.

- `PROJECT_STATE_MATRIX.md`: complete inventory, migration map, research-stage
  status, decisions, and pending or unverified work.
- `dataset/`: verified notes about the source and data characteristics.
- `exploratory_analysis/`: documentation of existing EDA, association analysis,
  and visualization outputs.
- `preprocessing/`, `modeling/`, and `final_evaluation/`: reserved for future
  documentation. They remain empty when no completed work is evidenced.

Completed work is documented only when supported by existing files or outputs.
Pending and unverified items are explicitly separated from completed work.
