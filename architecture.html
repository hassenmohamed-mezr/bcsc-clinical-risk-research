BCSC Risk Estimation: System Architecture

How raw BCSC risk data becomes calibrated one-year breast cancer risk probabilities: from data conversion and preprocessing, through model training, to the inference entry point used by an AI agent.

Input: risk.txt Selection: weighted PR-AUC Calibration: sigmoid Output: 4 probabilities + weighted average

1. High-level system architecture

The end-to-end pipeline. Data flows from the raw file to split datasets, fitted preprocessing artifacts and trained models, which are combined at inference time.

2. Training architecture

Each model gets its own encoder. Candidates are compared with weighted 5-fold cross-validation and selected by weighted PR-AUC, then refit on the full training set and calibrated.

flowchart TB
    X["Training X"] --> Enc["Per-model
encoder"]

    Z --> CV["Weighted
5-fold CV"]
    CV --> Select["Select by
weighted PR-AUC"]
    Select --> Fit["Final fit on
full train"]
    Fit --> Cal["Sigmoid calibration
ensemble=False"]
    Cal --> Save["Joblib
model artifact"]

3. Inference architecture

A patient record is normalized, mapped to BCSC coding, encoded by each model's fitted transformer, scored, and aggregated using the configured model weights.

    P["Human patient

    HumanMap --> IF["Interface-coded
DataFrame"]
    IF --> Mapper["RawInputMapper

    Mapper --> BCSC["BCSC-coded
DataFrame"]
    BCSC --> Pipe["Per-model fitted
ColumnTransformer"]
    Pipe --> Encoded["Encoded matrix"]
    Encoded --> Model["Calibrated model
predict_proba"]
    Model --> Prob["Positive-class
probability"]
    Prob --> Agg["Weighted average
(SUPMT_CONFIG.MODEL_WEIGHTS)"]
    Agg --> Out["Printed
probabilities"]

5. Key components

Where to look for each responsibility.

StageModuleResponsibility
Datasrc/data/risk_to_csv.pyConverts raw risk.txt to CSV and filters it.
Datasrc/data/load_splits.pyLoads the train, validation and test splits.
Preprocessingsrc/preprocessing/fit_preprocessing.pyFits per-model encoders and saves the mapping artifacts.
Preprocessingsrc/preprocessing/raw_input_mapping.pyMaps human and interface input to BCSC coding.
Trainingsrc/training/train_models.pyRuns weighted CV, selection, final fit and sigmoid calibration.
InferenceSUPMT.pyScores a patient with each model and returns the weighted average.
